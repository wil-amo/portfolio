# Portfolio — William Amo Pereira

Portfólio de Desenvolvedor Backend Java (foco em vaga júnior).

**URL:** https://wil-amo.github.io/portfolio/

## Stack
- HTML5 semântico, CSS3 (custom properties, grid, flexbox) e JavaScript puro (IntersectionObserver)
- Sem dependências de build — deploy direto no GitHub Pages

## Estrutura
```
index.html        página única (hero, sobre, projetos, skills, experiência, formação, contato)
css/style.css     tema escuro com acento teal, responsivo (mobile-first breakpoints)
js/main.js        menu mobile, scroll spy, reveal on scroll, barra de progresso
william-cv.pdf    CV para download
```

## Atualizar
1. Edite os arquivos e faça commit para a branch `main`.
2. O GitHub Pages publica automaticamente.
